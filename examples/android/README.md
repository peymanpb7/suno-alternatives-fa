# examples/android/README.md

نمونهٔ کلاینت اندروید: نحوهٔ استفاده

1. توکن Hugging Face خود را بگیرید و آن را در یک کانال امن (نه در repo) قرار دهید.
2. در Android Studio، پروژهٔ جدیدی ایجاد کنید و dependenciesهای ذکرشده را اضافه کنید.
3. فایل examples/android/MainActivity.kt را با UI ساده (دکمه تولید) وارد کنید.
4. اجرا کنید و خروجی WAV را پخش کنید.

توجه: بسته به مدل انتخابی، ممکن است خروجی به صورت base64 یا باینری باشد — آن را طبق داک مدل پردازش کنید.
