# suno-alternatives-fa

راهنمای قانونی و جایگزین‌های متن‌باز برای Suno (فارسی).

این نسخهٔ ارتقا یافته مخصوص کاربرانی است که با موبایل اندروید کار می‌کنند و می‌خواهند به صورت قانونی و عملی تولید صوتی/موسیقی را از روی دستگاه‌های موبایل یا با استفاده از سرویس‌های میزبانی‌شده پیاده‌سازی کنند.

هدف
- ارائه مسیرهای قانونی برای دسترسی به قابلیت‌های تولید صوتی
- معرفی راه‌حل‌های متن‌باز که می‌توانید محلی یا در سرویس‌های ابری اجرا کنید
- راهنمای گام‌به‌گام برای شروع سریع و نمونهٔ کدهای کلاینت اندروید برای فراخوانی سرویس‌های تولید صوت

هشدار حقوقی و اخلاقی
- این مخزن به هیچ‌وجه روش‌های دور زدن پرداخت یا استفادهٔ غیرقانونی از سرویس‌های پولی را آموزش نمی‌دهد.
- برای استفاده از سرویس‌های تجاری مثل Suno، همیشه از پلن‌ها و لایسنس رسمی آن سرویس استفاده کنید.

بخش‌های مهم
- setup-android.md — راهنمای کامل برای پیاده‌سازی از اندروید (این فایل را ببینید)
- setup-local.md — اجرای محلی مدل‌ها (GPU/PC)
- alternatives.md — فهرست جایگزین‌ها
- examples/android/ — نمونهٔ کد اندروید (Kotlin) برای فراخوانی API تولید صوت و پخش آن
- examples/ — نمونهٔ اجرای محلی (MusicGen)

شروع سریع برای کاربران اندروید
1. اگر می‌خواهید مدل سنگین را اجرا کنید: از راهنمای setup-local.md استفاده کنید و سپس یک سرور کوچک (Flask/Express) بسازید تا اندروید با آن صحبت کند.
2. اگر می‌خواهید مستقیم از موبایل استفاده کنید (بدون اجرا روی دستگاه): از سرویس‌های میزبانی‌شده امن مثل Hugging Face Inference API یا Replicate استفاده کنید؛ نمونهٔ کلاینت در examples/android راهنمایی شده است.

کمک و مشارکت
- اگر می‌خواهید محتوای بیشتری اضافه کنید یا تجربهٔ اجرای یک مدل را به اشتراک بگذارید، Pull Request باز کنید یا Issue بسازید.
