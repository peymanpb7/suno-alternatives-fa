# suno-alternatives-fa

راهنمای قانونی و جایگزین‌های متن‌باز برای Suno (فارسی).

این مخزن به زبان فارسی توضیح می‌دهد چگونه به صورت قانونی به تولید موسیقی/صدا بپردازید، جایگزین‌های متن‌باز را معرفی می‌کند، و مثال‌های عملی برای شروع سریع فراهم می‌کند.

هدف
- ارائه مسیرهای قانونی برای دسترسی به قابلیت‌های تولید صوتی
- معرفی راه‌حل‌های متن‌باز که می‌توانید محلی یا در سرویس‌های ابری اجرا کنید
- راهنمای گام‌به‌گام برای شروع سریع به همراه مثال‌های عملی

هشدار حقوقی و اخلاقی
- این مخزن به هیچ‌وجه روش‌های دور زدن پرداخت یا استفادهٔ غیرقانونی از سرویس‌های پولی را آموزش نمی‌دهد.
- برای استفاده از سرویس‌های تجاری مثل Suno، همیشه از پلن‌ها و لایسنس رسمی آن سرویس استفاده کنید.

شروع سریع
1. صفحه مخزن را ببینید و فایل setup-local.md را برای نصب محلی دنبال کنید.
2. برای مثال سریع، به examples/generate_music.py نگاه کنید.

ساختار مخزن
- README.md — این فایل
- alternatives.md — معرفی جایگزین‌های متن‌باز و لینک‌ها
- setup-local.md — راهنمای نصب و اجرای محلی (گام‌به‌گام)
- examples/ — نمونه‌های کد
  - generate_music.py — مثال تولید موسیقی با MusicGen (audiocraft)
  - requirements.txt — وابستگی‌های نمونه

کمک و مشارکت
- اگر می‌خواهید محتوای بیشتری اضافه کنید یا تجربهٔ اجرای یک مدل را به اشتراک بگذارید، Pull Request باز کنید یا Issue بسازید.
